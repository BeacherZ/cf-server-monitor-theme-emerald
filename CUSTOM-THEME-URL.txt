# 探针后台「自定义主题 URL」要填的地址

```
https://github.com/BeacherZ/cf-server-monitor-theme-emerald/tree/e199fe09105c68e3f45b971e81b9d6da54534ba4
```

## 填在哪

CF Server Monitor 后台 → 设置 → 主题 → 「自定义主题 URL」→ 粘贴上面的地址 → 点「预览」→ 点「启用自定义」→ 保存。

## 这个地址是什么

- 它指向本仓库 `build` 分支的一次提交（`e199fe0`），里面是编译好的 `index.html` + `assets/`。
- 探针只认这个分支的产物，不读 `main` 分支的源码。
- 写死 commit id（而不是写 `build`）是为了固定版本：以后重新构建也不会悄悄换掉正在用的主题。

## 改完代码后地址会变

重新构建并推送后，会得到一个新的 commit id，届时把新地址替换进来即可（终端最后一行会打印新地址）。步骤见 README 的「重新构建并发布」。
